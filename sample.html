Jetpack Compose'da recomposition'ı anlamak

Bu bir örnek yazıdır. Kendi yazını yazarken bu bölümü değiştir. Aşağıda kullanabileceğin bütün öğelerin nasıl göründüğünü görebilirsin — paragraf, başlık, liste, alıntı ve kod.

Bir ara başlık

Normal bir paragraf böyle görünür. Metnin satır uzunluğu okumayı kolaylaştıracak şekilde ayarlandı. İçine bağlantı ya da satır içi kod ekleyebilirsin.

  • Madde işaretli liste öğesi
  • İkinci öğe
  • Üçüncü öğe

Kod bloğu

@Composable
fun Sayac() {
    var sayi by remember { mutableStateOf(0) }
    Button(onClick = { sayi++ }) {
        Text("Tıklanma: $sayi")
    }
}
Önemli bir düşünceyi vurgulamak için alıntı bloğu kullanabilirsin.
